# Thermoviscoelastic-laminate-theory
Laminate theory python code to calculate the cure deformations of composite laminates, including the long-term relaxation deformations.
For more application information, please refer to the following:
Prediction of Process-Induced Residual Stresses in Thermoplastic Composites (DOI: 10.1177/002199839002400603.)
Thermoviscoelastic Analysis of Residual Stresses and Warpage in Composite Laminates (DOI: 10.1177/002199839202600606.)
Viscoelastic‑Crystallization Laminate Theory for Process Stresses in Thermoplastic Composites (DOI: 10.1016/j.ijmecsci.2026.112056.)
